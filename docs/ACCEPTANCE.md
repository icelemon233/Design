# Cinna Design 重构与验收记录

本次工作保留 React 18、TypeScript、Vite 和 pnpm 工作区，采用 Cinna 独立 API。行为参考 Ant Design，视觉延续云蓝、奶油白、可可色、圆角和柔和按压反馈。

## 已完成的结构调整

- 组件实现、公开类型和测试按功能归档，移除按大类堆叠的实现文件。
- 受控状态、通知队列、Escape 层级、焦点/滚动锁、浮层定位和主题继承由共享内部模块维护。
- 库样式与站点样式拆分；库盒模型规则限定在 Cinna 组件内。
- 64 个已有文档页面按路由懒加载，API 表由公开类型生成，新增的完整示例直接展示实际运行源码。
- 构建和 GitHub Pages 部署脚本兼容 Windows；加入格式、架构、包产物/SSR 和浏览器 CI。
- 原创云朵甜点精灵看板娘包含全身立绘、头像和压缩资源，已用于首页、站点标识和 Loading。

## 复现与边界

使用 Node.js 24+ 和仓库指定的 pnpm。执行 `pnpm check`、`pnpm format:check` 和 `pnpm test:e2e`；浏览器需先执行 `pnpm exec playwright install chromium`。Windows 本机使用已安装 Chrome，CI 配置使用 Chromium 并分别构建 Windows、Ubuntu。此次未执行 Safari、Firefox 或实体手机验收。

组件验收针对现有文档承诺和常用功能，不是 Ant Design 全量 API 兼容认证。Upload 验证了真实文件选择和模拟请求进度/回调；生产上传接口由使用方通过 action 或 customRequest 接入。自动无障碍检查补充了键盘和视觉检查，不能替代完整的人工辅助技术审计。
